# Student Management System

A Python command-line application for managing student records. The project supports adding, viewing, searching, updating, and deleting students, with data stored permanently using JSON.

## Features

- Add new students
- View all students
- Search students by ID
- Search students by name
- Update student information
- Delete students
- Prevent duplicate student IDs
- Validate student information
- Store student data using JSON
- Persistent data storage
- Automated testing with pytest

## Technologies Used

- Python
- JSON
- pytest
- Git
- GitHub
